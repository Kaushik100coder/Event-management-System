# Event Management System

## 📌 About the Project
This project is a full-stack Event Management System built using MERN stack.

## 👨‍💻 Team Project
This project was developed as a team project.

### 👥 Team Members
- Kaushik Das 
- Shayan Mondal

## ⚙️ Features
- Event creation and management
- User authentication
- Backend API integration
- Frontend UI for users

## 🛠️ Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB

## 🚀 How to Run
1. Clone the repository
2. Run frontend and backend separately
3. Install dependencies using npm
